NATURAL LANGUAGE PROCESSING

LLMを活用した
数学解説データセットの構築

近年、LLMの学習を目的として、数学の問題と解答を 含むデータセットが構築されています。 一方で、数学の解説を対象としたデータセットは 十分に整備されていません。

そこで、既存の問題・解答データをもとに LLMで解説を自動生成し、数学解説データセットを 構築する研究に取り組んでいます。

特に、AIが生成する文章を人が読みやすい形式に整えるため、 プロンプトや出力形式の改善を繰り返しています。

THEME 数学解説データセットの構築
TECHNOLOGY Python / LLM / 自然言語処理
CHALLENGE 生成文章の正確性・読みやすさの改善
GOAL 数学を理解しやすくするためのデータ整備
