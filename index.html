NATURAL LANGUAGE PROCESSING

LLMを活用した
数学解説データセットの構築

近年、LLMの学習に利用する数学の問題と解答を含む データセットが構築されています。 一方で、数学の解説を対象としたデータセットは 十分に整備されていません。

そこで、既存の問題・解答データを活用し、 LLMによって解説を自動生成することで、 数学解説データセットを構築する研究に取り組んでいます。

RESEARCH THEME 数学解説データセットの構築
TECHNOLOGY Python / LLM / 自然言語処理
FOCUS 解説の正確性・読みやすさ・生成品質
GOAL 数学をより理解しやすくするためのデータ整備
